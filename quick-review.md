# Quick Review

## React JS
A powerful JavaScript library for building user interfaces, particularly single-page applications.

## .NET Web APIs
Frameworks for building RESTful APIs that enable different software applications to communicate.

## Microservices
Architectural style that structures an application as a collection of loosely coupled services, each deployed independently.

## JavaScript
A versatile programming language used for web development, enabling interactive web pages and server-side scripting.

## C#
A modern, object-oriented programming language developed by Microsoft, ideal for building Windows applications and web services.

## Azure
Microsoft's cloud platform for building, deploying, and managing applications and services through a global network of datacenters.

## SQL
A standard language for managing and manipulating relational databases, essential for data storage and retrieval.
