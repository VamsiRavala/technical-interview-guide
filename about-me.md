# About Me

Hi, I'm Vamsi. I'm a .NET Lead with 13 years of experience. I've been in the US for over 3 years, and before that, I worked in India.

When I moved to the US, I started by supporting a legacy ESP system built with VB6 and DB2 for kroger. ESP stands for Enterprise Sales Promotion, which is used to manage promotions and pricing at corporate and division levels. My role focused on production support, bug fixes, and overall system stability.

For the last 8 months, I've been working on modernizing the ESP system, which we call PPM. We're using .NET Core web APIs, microservices, React, SQL Server, and ML.NET for forecast analysis. I also use Git Copilot for code reviews and whenever needed. The project is delivered in phases using Agile.

As the .NET Lead, I handle end-to-end delivery, lead the team, build secure APIs, manage Azure CI/CD, and work closely with QA and product owners to deliver high-quality solutions on time.
